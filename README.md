# Timeline Dashboard

React 18 + TypeScript + Vite implementation of the frontend assignment.

## Stack

- React 18
- TypeScript
- Vite
- Base UI
- Tailwind CSS

## Run Locally

```bash
npm install
cp .env.example .env
npm run dev
```

The backend base URL is configured with `VITE_BACKEND_BASE_URL`. The default is the assignment backend:

```bash
VITE_BACKEND_BASE_URL=https://fractaldmsdev.centralindia.cloudapp.azure.com
```

## Checks

```bash
npm test
npm run lint
npm run build
```
